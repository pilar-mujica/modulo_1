# modulo_4
## En este Módulo 4, confeccionamos un artículo en formato distill. 
### En este relacionamos distintos conflictos globales actuales con la industria oleícola.
Para esto, primero buscamos distintos informes que tuviesen datos útiles para armar el artículo. Luego, usando herramientas de distintas inteligencias artificiales armamos un archivo json recopilando los datos útiles (en general cuantitativos) de los informes leídos. Con este archivo json armamos la primer versión, la cuál revisamos y modificamos para obtener la versión final entregada.
